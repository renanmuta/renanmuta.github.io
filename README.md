# Renan Muta academic website — reference-style version

This version uses a native/system sans-serif stack rather than Inter and adopts a
more compact academic layout inspired by the proportions of the reference site.

## Edit homepage text
Open `index.html`. The main paragraphs are inside `<div class="profile-copy">`.

## Edit research
Open `research.html`. Each paper is inside `<article class="paper">`.

## Profile picture
`Picture.jpeg` is copied byte-for-byte from the uploaded image and has not been edited.
CSS only controls how large it is displayed in the browser.


## Light / dark mode

The sun/moon button in the navigation switches themes. The site remembers the
visitor's choice in the browser and otherwise follows the operating-system theme.




## Media page

Edit `media.html` to add, remove, or reorder media coverage. Each item is inside
`<article class="media-item"> ... </article>`.
